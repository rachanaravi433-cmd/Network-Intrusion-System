# Dataset

Synthetic HTTP-request payloads for testing the Aho-Corasick IDS.

| File | Contents |
|---|---|
| payloads.txt | 200 payloads, one per line (150 normal, 45 attacks, 5 look-alike clean lines) |
| payloads_labels.csv | ground truth: line number, expected number of matches, attack/clean |
| signatures.txt | the 6 default signatures (same as built into Main.java) |
| generate_dataset.py | regenerates the files (seed 42, so the output is reproducible) |

## How to use
1. Compile and run: `java -cp out ids.Main`
2. Choose **5. Scan a text file** and enter `data/payloads.txt`
3. Compare "Scanned L line(s); F flagged" with the numbers in payloads_labels.csv.

## Source
Signatures are common SQL-injection, path-traversal, command-injection and XSS patterns.
Payloads are generated by a script (random normal requests, attack strings inserted, mixed
case variants, and look-alike lines that must NOT match). Synthetic data is used so that
the expected result of every line is known exactly.
